# Changelog

## 0.2.2 — 2026-10-25

- 节点默认文案改为英文，并通过 ComfyUI 原生 locales 提供中英文名称、参数标签和提示。
- 框选按钮与操作提示跟随 ComfyUI 语言设置切换，保留稳定的节点和输入标识符。
- 清理英文 README 中混入的中文按钮说明。

## 0.2.1 — 2026-10-25

- 框选预览保持原图亮度，移除暗色遮罩和区域填充，增加八个可见拖拽手柄。
- 绘制调整仅作用于 WeVisOne 框选画布，保留原生交互和坐标保存方式。
- 整理公开安装说明、示例说明、许可证、源码检查 CI 和实际测试截图。
- 修复 API 示例生成时框选数组包装被校验器移除的问题。

## 0.2.0 — 2026-10-25

- 增加图片框选节点和自动连线入口，复用 ComfyUI 原生画布。
- 自动将画布坐标换算回原图像素坐标。
- 增加可视化框选与黑白 MASK 预览工作流。

## 0.1.0 — 2026-10-25

- 接入官方 WeVisOne-VL 2B／4B 的检测、指代、指点、计数、OCR、分割与抠图。
- 接入 Mask2Alpha 的 MASK、框和点击提示。
- 增加 Transformers 4.57 配置兼容层、ComfyUI 模型管理和中断支持。
